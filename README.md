# Island Royale

A 2D battle royale game: 40 players, 19 guns, shrinking zone.
The APK is built automatically by GitHub Actions.

## Download the APK
Open the Releases section on the right side of this page (or the Releases tab) and download `island-royale.apk` from the latest release.
Copy it to your phone and install it (allow installs from unknown sources).

To rebuild, push a change or use "Run workflow" on the Actions tab.
