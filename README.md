# Island Royale

A 2D battle royale game: 40 players, 19 guns, shrinking zone.
The APK is built automatically by GitHub Actions.

## Get the APK
1. Open the Actions tab and select the latest "Build Android APK" run.
2. Download the `island-royale-apk` artifact (a zip) from the bottom of the run page.
3. Unzip it, copy `app-debug.apk` to your phone and install it (allow installs from unknown sources).

To rebuild, push a change or use "Run workflow" on the Actions tab.
